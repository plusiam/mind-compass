# 🧭 마음여행 길잡이

함께 쓰면 좋은 정서조절 웹 활동지 · https://plusiam.github.io/mind-compass/

대구마음교육연구회(2026 사회정서교육 교사연구회)가 만든 초등 5~6학년 17차시 사회정서교육 프로그램 『마음여행』과 함께 쓰는 웹 활동지입니다. 설치·회원가입 없이 태블릿·크롬북·전자칠판에서 씁니다.

## 사용 원칙
1. 과정안 없이도 수업이 됩니다. 웹 활동지는 원고 활동을 확장하거나 대체할 때 골라 씁니다.
2. 학생이 쓴 내용은 그 기기의 브라우저(localStorage)에만 저장되고 서버로 보내지 않습니다. 공용 기기는 다 쓰면 「내 기록 지우기」를 누릅니다.
3. 상담을 대신하지 않습니다. 정답·점수·순위가 없습니다.

## 구성
| 주소 | 내용 |
|---|---|
| `/` | 첫 화면: 17차시 카드, 영역 고르기 |
| `/1/` | 1차시 마음 여행, 함께 출발 (출발 카드는 저장하지 않고 인쇄·PDF·그림으로만) |
| `/14/` | 14차시 마음 신호에 닻 내리기 (선생님께 드리는 쪽지는 저장하지 않음) |
| `/15/` | 15차시 다시 튀어 오르는 힘 |
| `/16/` | 16차시 도움을 청하는 용기 |
| `/17/` | 17차시 마음 여행을 돌아보며 |

3·5·6·7·13차시는 여한기가 2025~2026년에 만든 기존 공개 도구로 연결합니다(연구회 개발 자료 아님).

## 만든 사람
- 『마음여행』 집필: 한소연(1·17차시) · 이영미(2~4차시) · 이현주(5~7차시) · 김상일(8~10차시) · 신지수(11~13차시) · 여한기(14~16차시)
- 웹 구현: 여한기(대구남부초)
- 활동 문구는 『마음여행』 원고를 따르며, 그 권리는 집필진과 대구마음교육연구회에 있습니다.
