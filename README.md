# 🧭 마음여행 길잡이

함께 쓰면 좋은 정서조절 웹 학습지 · https://maeum-edu.vercel.app/

대구마음교육연구회(2026 사회정서교육 교사연구회)가 만든 초등 5~6학년 17차시 사회정서교육 프로그램 『마음여행』과 함께 쓰는 웹 학습지입니다. 설치·회원가입 없이 태블릿·크롬북·전자칠판에서 씁니다.

## 사용 원칙
1. 과정안 없이도 수업이 됩니다. 웹 학습지는 『마음여행』 활동을 확장하거나 대체할 때 골라 씁니다.
2. 학생이 쓴 내용은 그 기기의 브라우저(localStorage)에만 저장되고 서버로 보내지 않습니다. 공용 기기는 다 쓰면 「내 기록 지우기」를 누릅니다.
3. 상담을 대신하지 않습니다. 정답·점수·순위가 없습니다.

## 구성
| 주소 | 내용 |
|---|---|
| `/` | 첫 화면: 17차시 카드, 영역 고르기, QR, 빈 학습지 전체 PDF |
| `/1/` ~ `/17/` | 차시별 원고 활동지 웹학습지. 「인쇄·PDF」에서 빈 학습지(손글씨용)/쓴 내용, A4 세로·A3 세로(크게)·모둠판 A3 가로 |
| `/pdf/` | 미리 만든 빈 학습지 PDF: `lesson-01.pdf` ~ `lesson-17.pdf`, 전체 묶음 `mind-compass-blank-all.pdf` |
| `/assets/boards/` | 12·14·15차시 모둠판 원본 그림(연구회 제작) |

- 1차시 출발 카드, 14차시 선생님께 드리는 쪽지는 기기에 저장하지 않습니다.
- 3차시(익명 약점 쓰기)와 12차시(모둠판)는 화면에 쓰지 않고 빈 학습지 인쇄만 둡니다.
- 그림책 표지·삽화, 노랫말, 상표 로고·캐릭터, 출처를 알 수 없는 그림, AI 그림은 싣지 않습니다.
- 5·6·7·13차시의 「더 해 보기」는 룰루랄라 한기쌤이 2025~2026년에 만든 기존 공개 도구입니다(원고 활동지·연구회 개발 자료 아님).

## 만든 사람
- 『마음여행』 집필: 한소연(1·17차시) · 이영미(2~4차시) · 이현주(5~7차시) · 김상일(8~10차시) · 신지수(11~13차시) · 여한기(14~16차시)
- 웹 학습지 제작: 룰루랄라 한기쌤
- 활동 문구는 『마음여행』 원고를 따르며, 그 권리는 집필진과 대구마음교육연구회에 있습니다.

## 사용한 공개 라이브러리
- html2canvas 1.4.1 (MIT) — 그림으로 저장
- qrcode-generator (MIT) — QR
